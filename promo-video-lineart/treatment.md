# TimePulse · 产品介绍片导演案 (Treatment)

## 0. 交付与约束 (从用户 brief 提炼)

- **产品**：TimePulse — 美观、优雅、沉浸的多功能计时器 / 时光管理 / 专注陪伴工作台。类别：消费级效率工具 (macOS / Windows / Android / Web)。
- **一句话记忆点**：把散落一天的每一段时间，收进一张安静、漂亮的白纸上。
- **硬约束 (用户指定，视为项目基调)**：
  1. **禁用蓝紫色系**（不用产品默认的经典蓝 / 靛蓝 / 紫罗兰）。
  2. **白底为主**（羊脂纸白，与产品 UI 同源）。
  3. **线条更多**：全片以单色墨线绘制——极细网格、等高线、手绘圈环、globe 经纬、放射专注线、引导线。
  4. **电影级质感**：浅景深 (背景线虚化)、胶片颗粒、暗角、缓慢推轨 / 摇移 / 视差。
  5. **2D 场景 + 2D 人物**：以扁平线描的方式重建"使用产品的一天"（标记日历 / 伏案专注 / 勾选清单 / 移动端同步）。

## 1. 导演定位

- **调性滑杆**：精确 −0.3 ↔ 俏皮（硬核计时，但用弹性微动效软化）｜沉静 −0.5 ↔ 高燃（112 BPM 中段快切）｜高级 +1.5（大留白、纸白、克制的强调色）｜极客 −0.2 ↔ 人文 +1.2（农历、寄语、手写体、2D 人物的一日）｜经典 +0.8 ↔ 先锋 +1.5（新一代陪伴式时光工作台）。
- **一句话**：「Calm, premium, human, new — 一张会呼吸的纸，一支会走路的墨线。」
- **语言**：`hand-drawn`（墨线自绘）为骨 × `cursor-demo/product-ui`（重建真实 UI 卡片）× `character`（2D 人物的一日）——以一条**贯穿全片的连续墨线**作 spine，把各场景串成一条动线。
- **与 house style 的区别**：不是"暗底+暖橙+bone 衬线"，而是**纸白底 + 单色墨线描 + 少量余烬橙**；主角是线，不是字。次要色来自产品自身的三级优先级 / 番茄钟主题（翡翠绿 / 玫瑰 / 琥珀），与余烬橙构成"中性纸面 + 一个信号色"的克制关系。

## 2. 三个方向（用户已指定风格，此处只留各自 palette 供日后重组）

- **A · Fit ——「纸上一日」**（采用）：白纸连续世界，一支墨线画出一天；2D 人物在各场景劳作；真实 UI 卡片以扁平墨线重绘。
- **B · Amplify ——「线稿解剖」**：把 TimePulse 拆成工程蓝图的线稿剖面（计时矩阵 / 云同步 / 双轨存储），更像一张技术海报。
- **C · Unexpected ——「墨线的旅行」**：主角就是那支墨线本身，它自己走完一天，UI 顺着它的路径长出来。

Palette（A，已采用）：ground `#FBF9F4` 72 · surface `#F1EEE5` 12 · ink `#191A1D` 8 · muted `#5E5A52` 4 · accent(ember) `#F0662B` 2.5 · state(emerald `#2E9E68` / rose `#DE4A6B` / amber `#E0A21A` / red `#E2503F`) 1.5 — from：产品 UI 截图地面与强调色、logo 余烬橙、待办三级色标与番茄钟翡翠/玫瑰主题。

## 4. 四张关键帧与连续性链路

- **四张帧**：hook（钟环自绘）｜hero（禅钟满幅）｜densest（burst 云同步镜）｜end（Logo 收束）。
- **连续性链路（一物带眼）**：
  1. hook 钟环圆心 → countdown 数字格的分隔点；
  2. countdown「秒」格圆角 → focus 番茄环（同一圆）；
  3. focus 环上余烬"当下点" → todo 勾选框（点变成勾）；
  4. todo 完成条 → burst 首镜的一条墨线，被 8 个镜头接力传递（全片 spine）；
  5. burst 末镜平台行 → stop 的留白；
  6. stop 的一行字 → zen 禅钟的下缘微光；
  7. zen 数字轮廓 → mark 收束成的 Logo 脉冲钟。
