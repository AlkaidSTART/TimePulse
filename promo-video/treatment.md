# TimePulse 30秒产品发布片导演案 (Treatment)

## 1. 导演定位 (Director Brief)

- **产品定位**：致力于成为最美观、优雅且沉浸的现代化多功能计时器、时光管理与专注陪伴工作台。
- **核心记忆点**：高定美学界面 + 全能计时矩阵 + 极简沉浸禅模式 + 跨平台原生与云同步。
- **调性滑块 (Personality Sliders)**：
  - 精确 ↔ 俏皮：-0.5（硬核计时系统兼具元气打气温润弹性动效）
  - 沉静 ↔ 高燃：0.0（沉静工位氛围与 118 BPM 节拍利落快切碰撞）
  - 高级 ↔ 亲和：+1.2（Apple / Linear 级负空间、深色曜石质感、毛玻璃微光）
  - 极客 ↔ 人文：+0.6（二十四节气农历与晨昏寄语 + Tauri v2 / Rust / React 19 硬核工程）
  - 经典 ↔ 先锋：+1.5（新一代桌面端陪伴与时光管理工具）
- **选定风格 (Chosen Direction)**：`A · Fit (精准美学发布会 · Linear-Apple Hybrid)`
  - 连续主线（时间流淌与钟表脉动）穿插中段高密度功能切片（倒数/番茄/待办/禅模式）。

## 2. 旁白稿与字音标记 (Narration & Word Cues)

- **00.0s – 03.5s (Hook 开场引入)**
  > 旁白：「时间，不该只是冰冷的数字流逝。」
  > 画面：深邃曜石背景中，TimePulse 发光时间环与 Logo 粒子聚拢，光晕轻柔脉动。

- **03.5s – 08.8s (Matrix 全能计时矩阵)**
  > 旁白：「长期倒数日精准锚定每一个重要节点，短期番茄钟沉浸聚焦当下每一分钟。」
  > 画面：卡片 3D 浮动入场，倒数日进度环动态推进至 100%，番茄钟翡翠绿光环平滑翻转跳动。

- **08.8s – 14.5s (Cheer & Todo 元气打气与待办)**
  > 旁白：「农历节气与晨昏温润问候，三色优先级待办清单，一键收纳为桌面常驻悬浮挂件。」
  > 画面：霜降节气与每日灵感名言卡片展开；待办三色标签逐条勾选动画，右下角一键折叠收拢为微挂件（Widget）。

- **14.5s – 21.0s (Zen Mode 沉浸极简禅模式)**
  > 旁白：「一键进入纯净禅模式，隐去所有干扰，让桌面回归最专注的宁静。」
  > 画面：所有浮动 UI 优雅向外散开淡出，巨幅极简数字时钟呼吸微位移，工位氛围拉满。

- **21.0s – 25.5s (Ecosystem 原生跨端与云同步)**
  > 旁白：「双轨存储与云端增量同步，macOS、Windows、Android，多端原生奔跑。」
  > 画面：三端设备多重展示，Supabase TLS 锁徽章与 SQLite 极速徽章环绕点亮。

- **25.5s – 30.0s (Hero 定格收尾)**
  > 旁白：「TimePulse —— 优雅掌控时间，沉浸陪伴每一个当下。」
  > 画面：Logo 发光居中定格，优雅光波向外扩散，标语「最美观的时光管理工作台」与开源体验徽章定格。

## 4. 连续性视觉链路 (Continuity Chain)

- **转场 1 (Hook → Timers)**：开场发光圆环的中心圆点，在 3.5s 顺滑放大扩展，直接蜕变为倒数日环形进度条的圆心。
- **转场 2 (Timers → Cheer)**：番茄钟的卡片圆角边缘在 8.6s 向右展开延伸，自然翻转为元气打气与节气名言卡。
- **转场 3 (Cheer → Todo & Widget)**：名言卡下边缘平滑滑出待办清单，待办清单打勾完成后整体向右下角吸入缩放，化作悬浮微挂件。
- **转场 4 (Todo → Zen)**：微挂件双击展开，波纹冲刷全屏，所有元素散开，中央时间数字蜕变成极简纯净禅时钟。
- **转场 5 (Zen → Ecosystem)**：禅时钟数字向深处淡入，macOS/Windows/移动端三块高精设备视窗从左右和正面推入。
- **转场 6 (Ecosystem → Hero)**：三端视窗向中心聚拢，重合汇聚为 TimePulse 标志性 Logo 徽标，定格品牌终帧。
